## ПРІОРИТЕТ 1 — Критичне (зламано, не працює)

### 1.1 PDF Експорт не працює
**Де:** `main.py`, приблизно рядки 1459–1478  
**Симптом:** Замість генерації PDF показується fallback-попередження  
**Що зробити:** Реалізувати справжній `QPrinter`-based PDF export  
**Критерій прийняття:** Натискання "Експорт PDF" → відкривається діалог збереження → файл .pdf створюється і відкривається у Preview

### 1.2 Мінімапа — placeholder
**Де:** `main.py`, приблизно рядки 3097–3101  
**Симптом:** Пункт меню є, але при натисканні нічого не відбувається або показується "coming soon"  
**Що зробити:** Або реалізувати справжню мінімапу (QGraphicsView у зменшеному масштабі), або заховати пункт меню повністю, щоб не вводити в оману  
**Критерій прийняття:** Або мінімапа показує реальний огляд сцени, або пункту меню немає взагалі

### 1.3 Zoom не центрується на курсорі
**Симптом:** Зум колесом миші центрується на (0,0) або на центрі вікна, а не на позиції курсора — незручно на великих схемах  
**Що зробити:** Перевизначити `wheelEvent` у `DiagramCanvas`, зум відносно позиції курсора через `setTransformationAnchor(QGraphicsView.AnchorUnderMouse)`  
**Критерій прийняття:** Зум завжди центрується під курсором

## ПРІОРИТЕТ 2 — Основний функціонал (відсутній, але потрібен)

### 2.1 Інструмент геометричних фігур (Shape Tool)
**Чого немає:** Неможливо додати кола, прямокутники, текстові мітки для анотацій схеми  
**Що зробити:** Додати на toolbar окремі кнопки:
- "Намалювати лінію" (вільна лінія між двома точками, не вузол-до-вузла)
- "Додати коло / еліпс" (просто форма, без даних вузла)
- "Додати прямокутник" (рамка для виділення групи)
- "Додати текстову мітку" (текст без рамки, для підписів зон)

**Технічно:** `QGraphicsEllipseItem`, `QGraphicsRectItem`, `QGraphicsLineItem`, `QGraphicsTextItem` — всі є в Qt без додаткових залежностей  
**Критерій прийняття:** Можна намалювати коло або рамку на порожньому місці полотна; фігуру можна переміщати і видаляти

### 2.2 Панель властивостей — тільки читання (потрібно редагування)
**Симптом:** Панель праворуч показує дані вибраного вузла, але редагувати поля можна лише через окремий діалог  
**Що зробити:** Зробити поля Назва і Примітка у боковій панелі прямо редагованими (`QLineEdit`, `QTextEdit` замість `QLabel`). Зміни застосовуються одразу при втраті фокусу або Enter  
**Критерій прийняття:** Клік по назві вузла у бічній панелі → поле стає редагованим → введення оновлює вузол без відкриття діалогу

### 2.3 Групування / Контейнери
**Чого немає:** Не можна виділити кілька вузлів і згрупувати їх у логічну групу  
**Що зробити:** 
- `Edit → Згрупувати вибране` або правою кнопкою → "Група"
- Група відображається як напівпрозорий прямокутник навколо вузлів
- Переміщення групи → всі вузли всередині рухаються разом  
**Критерій прийняття:** Виділив 3 вузли → "Група" → з'явилась рамка → переміщення рамки тягне всі вузли

## ПРІОРИТЕТ 3 — Покращення (бажано)

### 3.1 Авто-розміщення вузлів
**Чого немає:** Немає алгоритмів автоматичного розташування для великих схем  
**Що зробити:** Пункт меню `Вид → Авто-розміщення`:
- **Сітка** — розкласти вузли рівномірно по сітці (просто реалізувати)
- **Радіально** — центральний вузол, інші навколо (для ієрархій)  
**Критерій прийняття:** Схема з 20+ вузлів → "Авто-розміщення" → вузли розташовані читабельно без перекриттів

### 3.2 Snap-to-Grid (прив'язка до сітки)
**Чого немає:** Вузли переміщуються вільно, не вирівнюючись по сітці  
**Що зробити:** Чекбокс у меню `Вид → Прив'язка до сітки`. Якщо увімкнено — при відпусканні вузол "притягується" до найближчого вузла сітки  
**Критерій прийняття:** При увімкненій прив'язці вузли завжди стають рівно на лінії сітки

### 3.3 Рефакторинг main.py
**Проблема:** 3385 рядків в одному файлі — важко підтримувати  
**Що зробити (необов'язково зараз):** Розбити на підмодулі:
- `models.py` — Node, Link
- `items.py` — NodeItem, LinkItem, ShapeItem
- `dialogs.py` — NodeDialog, LinkDialog, SearchDialog
- `canvas.py` — DiagramCanvas
- `main.py` — тільки MainWindow + запуск  
**Важливо:** Це рефакторинг без зміни функціоналу. Робити лише після стабілізації функціоналу
