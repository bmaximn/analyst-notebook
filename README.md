# Редактор зв'язкових схем

Локальний десктопний застосунок для побудови схем взаємодій між особами, організаціями, телефонами та іншими об'єктами. Призначений для слідчих та аналітиків. Працює повністю офлайн, без інтернету та телеметрії.

---

## Вимоги

- macOS 12+ (arm64 або x86_64)
- Python 3.9 або новіший

---

## Запуск із вихідного коду

```bash
# 1. Клонувати репозиторій
git clone https://github.com/bmaximn/analyst-notebook.git
cd analyst-notebook

# 2. Створити віртуальне середовище
python3 -m venv .venv
source .venv/bin/activate

# 3. Встановити залежності
pip install -r requirements.txt

# 4. Запустити
python main.py
```

---

## Збірка .app для macOS

```bash
# Активувати середовище (якщо ще не активовано)
source .venv/bin/activate

# Встановити PyInstaller
pip install pyinstaller

# Зібрати .app
pyinstaller --windowed \
            --name "Link Diagram Editor" \
            --onedir \
            --hidden-import PyQt6.QtPrintSupport \
            main.py
```

Готовий файл буде у папці `dist/Link Diagram Editor.app`.

Щоб встановити — перетягни `Link Diagram Editor.app` до папки `/Applications`.

> **Примітка:** При першому запуску macOS може показати попередження «застосунок від невідомого розробника». Дозволити запуск можна через  
> **System Settings → Privacy & Security → Open Anyway**

## Функції

### Основні (реалізовано)

| Функція | Опис |
|---|---|
| 7 типів вузлів | Особа, Організація, Телефон, Транспорт, Документ, Подія, Локація |
| 4 типи зв'язків | Суцільна зі стрілкою, пунктирна, подвійна, двостороння |
| Редагування | Двічі клікнути на вузол або зв'язок |
| Переміщення | Drag & drop вузлів мишею |
| Фото | Прикріпити до вузла типу «Особа» |
| Undo / Redo | Cmd+Z / Cmd+Shift+Z (до 100 кроків) |
| Збереження | JSON-файл із вузлами, зв'язками та фото (base64) |
| Відкриття | Cmd+O або Файл → Відкрити |
| Autosave | Автозбереження кожні 5 хв у `~/.analyst_notebook_autosave.json` |
| Export PNG | Файл → Експорт → PNG |
| Export PDF | Файл → Експорт → PDF |
| Імпорт CSV | Файл → Імпорт CSV (nodes.csv) |
| Фільтр | Показати/сховати вузли за типом |
| Пошук | Ctrl+F — пошук по назві |
| Масштаб | Ctrl+/- або коліщатко миші |

### Формат CSV для імпорту (nodes.csv)

```
id,type,title,note,date,color,x,y
001,Person,Іван Петренко,підозрюваний,2024-01-15,#4A90D9,100,100
002,Phone,+380501234567,,2024-01-15,,300,100
```

Поля `note`, `date`, `color` — необов'язкові.
